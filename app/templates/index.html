03

{{ _('Componente estocástica — Proceso de Ornstein-Uhlenbeck') }}

{{ _('El residuo X(t) = T(t) − S(t) sigue un proceso de reversión a la media en tiempo continuo:') }}

dX = η(μ − X) dt + σ dWt

{{ _('Su discretización de Euler-Maruyama con paso dt = 1/365 da el esquema de simulación:') }}

Xt+1 = μ(1 − e−η) + e−η Xt + εt ,   εt ~ N(0, σε²)

{{ _('Los parámetros se estiman regresando ΔT = a + bT(t−1) + ε por MCO, de donde η = −ln(1+b) y μ = −a/b. Se generan n = 5 trayectorias y se toma la media como proyección estocástica.') }}
